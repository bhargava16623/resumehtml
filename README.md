# Resume HTML

A clean and professional HTML resume/CV template built with pure HTML. This project demonstrates proper HTML structure using semantic tags including headings, paragraphs, lists, tables, and sections.

## Features

- Clean and readable structure
- Semantic HTML tags
- Responsive table layouts
- Professional sections:
  - About Me
  - Skills
  - Experience
  - Projects
  - Education
  - Contact Information

## Setup Steps

1. Clone this repository:
   ```bash
   git clone https://github.com/bhargava16623/resumehtml.git
   ```

2. Navigate to the project directory:
   ```bash
   cd resumehtml
   ```

3. Open the HTML file in your browser:
   - **Option 1:** Double-click `resume.html` to open in your default browser
   - **Option 2:** Right-click `resume.html` and select "Open with" your preferred browser
   - **Option 3:** Use a local server (recommended for development)

## Usage

### Viewing the Resume

Simply open `resume.html` in any modern web browser (Chrome, Firefox, Safari, Edge).

### Customizing the Resume

1. Open `resume.html` in your preferred text editor
2. Modify the content to match your personal information:
   - Update name and title in the header
   - Edit the "About Me" section
   - Add/remove skills in the Skills section
   - Update work experience in the Experience table
   - Modify projects with your own work
   - Update education credentials
   - Change contact information

3. Save the file and refresh your browser to see changes

## Learning Objectives

This project demonstrates:
- Proper HTML document structure
- Use of headings (`<h1>`, `<h2>`, `<h3>`)
- Paragraph formatting (`<p>`)
- Unordered lists (`<ul>`, `<li>`)
- Table creation with headers and body (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`)
- Horizontal rules (`<hr>`)
- Text formatting (`<strong>`)
- Special characters (`&copy;` for copyright symbol)
